# OpenRoadVibes — Documentation

This folder contains all human‑readable documentation for the OpenRoadVibes project.

## Contents
- Architecture diagrams  
- Developer guides  
- API documentation  
- Calibration instructions  
- Data processing explanations  
- Research references  
- Contribution tutorials  

## Purpose
The `/docs` directory serves as the central knowledge hub for contributors and users.  
All long‑form explanations, diagrams, and guides should live here rather than in the root directory.

## Guidelines
- Use clear, concise language  
- Prefer Markdown for readability  
- Include diagrams when helpful  
- Keep documents modular and link between them
