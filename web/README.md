# OpenRoadVibes — Web Visualization

This folder contains the frontend tools for visualizing road roughness data.

## Responsibilities
- Rendering a map with roughness overlays  
- Displaying color‑coded road segments (green → red)  
- Providing filtering and exploration tools  
- Serving tiles generated by the backend  

## Structure
Typical contents:
- Leaflet or MapLibre web app  
- Tile rendering scripts  
- UI components  
- CSS/JS assets  
- Hosting instructions  

## Goals
Create a clean, intuitive interface for exploring global road roughness data.
