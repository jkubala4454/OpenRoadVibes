# OpenRoadVibes — Hardware

This folder contains all physical design resources for the OpenRoadVibes device.

## Responsibilities
- Documenting the reference hardware build  
- Providing wiring diagrams  
- Listing required components (BOM)  
- Offering PCB designs (optional)  
- Supplying 3D‑printable enclosure files  
- Sharing assembly instructions  

## Structure
- Schematics  
- BOM (Bill of Materials)  
- PCB files (if applicable)  
- Enclosure designs  
- Photos of reference builds  

## Goals
Make the hardware easy to build, affordable, and reproducible for contributors worldwide.
