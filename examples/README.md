# OpenRoadVibes — Examples

This folder contains sample data and example scripts to help contributors get started.

## Contents
- Sample log files  
- Example processing scripts  
- Demonstrations of roughness calculations  
- Jupyter notebooks (optional)  
- Tutorials for local analysis  

## Purpose
Provide hands‑on examples that illustrate how the system works end‑to‑end.

## Goals
Lower the barrier to entry and help new contributors validate their setup quickly.
