# OpenRoadVibes — Data Specification (ORV‑LF)

This folder defines the OpenRoadVibes Log Format (ORV‑LF), the standard for roughness data.

## Responsibilities
- Defining required and optional fields  
- Maintaining CSV and JSON schemas  
- Providing validation rules  
- Documenting version history  
- Offering example files  

## Structure
- `ORV-LF-v1.0.md` — primary specification  
- `schema.json` — JSON schema  
- `examples/` — sample logs  
- `changelog.md` — version history  

## Goals
Ensure consistent, high‑quality data across all devices and contributors.
